# 报销与归档合规检查清单

工具只做整理与归集，不判定发票真伪、不代理记账、不做纳税申报。以下检查项用于汇报"待办事项"，结论由财务或经办人确认。

## 一、票面合规（逐张）

1. 抬头为公司全称，与营业执照一致；税号（统一社会信用代码）一致。个人抬头、他方抬头不得报销。
2. 项目名称与业务实质一致，不能笼统写"办公用品"而不附清单（大额办公用品需附购物明细）。
3. 金额勾稽：不含税金额 + 税额 = 价税合计（大写与小写一致）。
4. 专用发票的地址、电话、开户行账号三项不是必填项，但购买方名称与税号必须完整。
5. 备注栏强制填写的情形：不动产租赁（房屋地址）、建筑服务（项目名称+地址）、运输服务（起运地、到达地、车种车号）、差额征税（"差额征税"字样）、单用途预付卡。
6. 发票号码唯一，无重复；重复报销是报销环节最常见的高风险点，同一发票号只允许报销一次。
7. 红字发票必须与原蓝字发票配对，冲减同类型、同期间金额，不得作为新费用列支。

## 二、时限

| 事项 | 口径 |
| --- | --- |
| 跨年票据 | 权责发生制下应计入费用发生期；上年未取得、次年汇算清缴前取得的可扣除，附说明 |
| 专票抵扣 | 认证确认期限已取消，但仍需在增值税发票综合服务平台确认用途（抵扣/不抵扣） |
| 会计档案保管 | 原始凭证及电子发票保存期限不少于 10 年，电子发票须保存原始电子文件 |
| 发票查验 | 全国增值税发票查验平台 npv.chinatax.gov.cn，可查近 5 年，单张发票每日查验次数有限 |

电子发票不能只留存打印件：报销、归档、审计抽查都可能要求提供原始 PDF/OFD/XML 文件。

## 三、支撑材料（大额或特定事项）

| 费用类型 | 应附材料 |
| --- | --- |
| 差旅费 | 出差审批单、行程单/登机牌、住宿水单 |
| 会议费 | 会议通知、签到表、会议纪要、议程 |
| 业务招待费 | 招待事由、客户单位与人数、陪同人员 |
| 培训费 | 培训通知、课程表、发票、参训名单 |
| 劳务费 | 劳务合同、身份信息、个税代扣凭证 |
| 固定资产 | 验收单、资产卡片、使用部门 |
| 装修/改良 | 合同、结算单、判断是否资本化 |

## 四、不能作为税前扣除凭证的情形

- 收据、白条、内部结算单（除税法明确允许的例外，如工资表、折旧表）
- 与生产经营无关的个人消费（家庭旅游、私人车辆日常使用）
- 用于集体福利、个人消费的专票进项（不得抵扣，但可作费用凭证）
- 已被冲红的蓝字发票

## 五、工具输出的异常清单对应处理

| 标记 | 处理动作 |
| --- | --- |
| 抬头与公司不符 / 购方税号不符 | 联系商家重开；个人抬头转由个人承担 |
| 疑似重复 | 核对是否同一张票的多次下载；保留一份，其余剔除并注明 |
| 缺发票号码 / 缺开票日期 / 缺金额 | 回票面或税务数字账户补齐，补齐后重跑 scan |
| 图片待人工读取 | 按 extraction-guide.md 的流程补录 overrides |
| 分类待确认 | 按业务实质确认，必要时与财务沟通后写入 overrides |
| 负数红冲票 | 与蓝票配对，冲减同类型金额 |
| 归属年度不符 | 按跨年票据规则处理 |
| 低于固定资产标准 | 一次性费用化，不作资产登记 |

## 六、汇报时的表述边界

- 可以说明：识别张数、金额合计、类型分布、异常条目及建议动作。
- 不可以说明：发票真伪、是否必然可抵扣、是否必然可税前扣除、账务处理结论。
- 需要时给出查验入口与所需材料清单，由经办人自行完成。
