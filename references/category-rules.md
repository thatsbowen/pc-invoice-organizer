# 发票类型归类规则（会计与税务口径）

分类目的有两个：一是费用性质归集（决定计入哪个会计科目），二是税前扣除与进项抵扣判断。两者口径不同，不要混用。

机器可读规则在 `category-rules.json`，按 `priority` 从高到低首次命中即停；本文件用于人工判断和复核，不参与自动匹配。

## 一、类型清单与科目归属

| 类型 | 典型票面项目/销售方 | 常见会计科目 | 判断要点 |
| --- | --- | --- | --- |
| 差旅费 | 住宿服务、客房、酒店、机票、铁路旅客运输、长途客运 | 管理费用—差旅费 / 销售费用—差旅费 | 出差期间的长途交通与住宿；出差地市内交通另归市内交通费 |
| 市内交通费 | 出租车、网约车、地铁、公交、交通卡 | 管理费用—交通费 | 员工市内公务出行 |
| 车辆使用费 | 加油、充电、车辆维修、车险、停车、通行费/ETC | 管理费用—车辆使用费 | 私车公用须有租赁协议，否则直接报油费有扣除风险 |
| 业务招待费 | 餐饮、宴请、礼品、娱乐、旅游、茶歇 | 管理费用—业务招待费 | 招待客户；附事由与客户名单。员工聚餐应归职工福利费 |
| 职工福利费 | 体检、团建、节日礼品、食堂、慰问 | 管理费用—职工福利费 | 集体福利；实物福利涉及个税 |
| 劳动保护费 | 工作服、安全帽、防护用品、防暑降温 | 管理费用—劳动保护费 | 生产经营必需，不并入个税 |
| 会议费 | 会议服务、会务、会场、研讨会 | 管理费用—会议费 | 须有会议通知、签到表、纪要，仅有发票不能证明真实性 |
| 培训费 | 培训、课程、学费、研修 | 管理费用—职工教育经费 | 与会议费区分；超限部分可结转以后年度 |
| 办公费 | 办公用品、文具、耗材、硒鼓、图书资料 | 管理费用—办公费 | 单价低、不资本化 |
| 印刷费 | 印刷、制版、晒图、标书制作 | 管理费用—印刷费 | 与广告宣传用的印刷品区分 |
| 房租物业费 | 房屋租赁、不动产经营租赁、物业费、仓库租赁 | 管理费用—租赁费/物业费 | 租赁发票备注栏须注明不动产详细地址 |
| 水电费 | 电费、水费、燃气、供暖 | 管理费用—水电费 | 转售水电按转售处理 |
| 通讯费 | 电信、移动、联通、宽带、专线 | 管理费用—通讯费 | 个人名义发票不得直接扣除 |
| 快递物流费 | 快递、物流、货运、仓储、装卸 | 销售费用—运输费/快递费 | 运输服务发票备注栏须注明起运地、到达地、车种车号 |
| 广告宣传费 | 广告、推广、展览、展位、媒体投放、设计制作 | 销售费用—广告宣传费 | 赞助支出不属广告费；烟草广告不得扣除 |
| 中介服务费 | 咨询、审计、法律、评估、检测、认证、代理、技术开发 | 管理费用—中介服务费/咨询费 | 与信息技术服务、研发费用区分，按合同实质判断 |
| 软件信息服务费 | 信息技术服务、云服务、SaaS、域名、服务器租赁 | 管理费用—信息服务费/软件服务费 | 订阅制按受益期分摊 |
| 维修费 | 维修、修理、保养、安装 | 管理费用—修理费 | 符合资本化条件的改良计入固定资产原值 |
| 保险费 | 财产保险、责任保险、雇主责任险 | 管理费用—保险费 | 为员工购买的商业人身保险一般归职工福利费 |
| 劳务费 | 劳务、劳务派遣、外包、临时用工 | 管理费用/成本—劳务费 | 须代扣代缴个税，与工资薪金区分 |
| 招聘费 | 招聘、猎头、背调、人才服务 | 管理费用—招聘费 | — |
| 银行手续费 | 手续费、账户管理费、结算费 | 财务费用—手续费 | 多以银行回单入账，非发票 |
| 税费 | 印花税、完税凭证、残保金、滞纳金 | 税金及附加 / 管理费用 | 完税凭证不属于发票，单独归档 |
| 固定资产 | 电脑、显示器、打印机、服务器、家具、空调 | 固定资产 | 单价达到企业资本化标准（默认 5000 元）或使用年限超 1 年 |
| 无形资产 | 软件著作权、专利、商标、软件授权 | 无形资产 | 按摊销计入损益 |
| 其他 | 未匹配任何规则 | 待定 | 必须人工确认，不得默认入账 |

## 二、易混情形对照

| 情形 | 结论 |
| --- | --- |
| 酒店发票含住宿+餐饮 | 整张按差旅费；餐饮部分如单独列示且为招待客户，可拆分为业务招待费 |
| 会议期间餐费 | 与会议同期、有会议证明的并入会议费；单独宴请客户归业务招待费 |
| 培训 vs 会议 | 有授课内容、学时、师资 → 培训费；以议事决策为主 → 会议费 |
| 技术服务 vs 信息技术服务 | 提供系统、软件、云资源 → 软件信息服务费；提供专业意见、鉴证 → 中介服务费 |
| 电脑、打印机 | 单价 ≥ 资本化标准 → 固定资产；低于标准 → 办公费（低值易耗） |
| 快递 vs 运输服务 | 小件寄递 → 快递物流费；承运货物 → 运输费，备注栏要求不同 |
| 加油、停车、通行费 | 归车辆使用费，不归差旅费（除非能明确对应某次出差行程） |
| 红字发票 | 与原蓝票配对，冲减同类型当期金额，不得单独作为新费用 |

## 三、税前扣除限额（需全年累计测算，单张发票不构成超限）

| 项目 | 限额 |
| --- | --- |
| 业务招待费 | 发生额 60% 与当年营业收入 5‰ 孰低 |
| 职工福利费 | 工资薪金总额 14% |
| 职工教育经费（培训费） | 工资薪金总额 8%，超限可结转 |
| 工会经费 | 工资薪金总额 2% |
| 广告宣传费 | 营业收入 15%（化妆品制造、医药制造、饮料制造 30%） |
| 补充养老/补充医疗保险 | 工资薪金总额各 5% |
| 公益性捐赠 | 年度利润总额 12%，超限可结转三年 |

## 四、修改规则的方式

- 新增关键词、调整优先级：改 `category-rules.json`，不要改 `invoice_tool.py`。
- 只对本次任务生效的个别调整：用 `--overrides` 的 `category` 字段，或在 `--profile` 的 `category_overrides` 写 `{"关键词": "类型"}`。
- 新增类型时同步补 `deduction_hint`，否则汇总表该行扣除口径为空。
